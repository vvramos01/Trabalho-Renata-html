## Atividade 2 - Hogwarts Legacy
Projeto inspirado no jogo Hogwarts Legacy, contendo múltiplas páginas conectadas entre si.

### Arquivos da atividade

- index.html → Página principal
- gameplay.html → Página sobre gameplay e personagem
- casas.html → Página sobre as casas de Hogwarts
- style.css → Arquivo de estilização CSS

### Recursos utilizados

#### HTML
- Estrutura semântica
- Links entre páginas
- Listas ordenadas e não ordenadas
- Imagens
- Vídeo incorporado

#### CSS
- Cor de fundo
- Alteração de fontes com Google Fonts
- Estilização de textos
- Seletores de tag, classe e id
- Box Model
- Bordas
- Hover em links
- Comentários e organização do código

### Tecnologias utilizadas
- HTML5
- CSS3

# Atividade 3 - Sweet Cake

Projeto de uma loja online de bolos utilizando HTML, CSS e JavaScript, contendo páginas conectadas entre si, responsividade e animações.

### Arquivos da atividade

- index.html → Página principal da loja
- bolos.html → Página com os bolos disponíveis
- promocoes.html → Página de promoções
- contato.html → Página de contato
- style.css → Arquivo de estilização CSS
- script.js → Arquivo JavaScript

### Recursos utilizados

#### HTML
- Estrutura semântica
- Links entre páginas
- Cards de produtos
- Imagens
- Menu de navegação

#### CSS
- Flexbox
- Grid Layout
- Responsividade
- Hover nos cards
- Animações
- Box Model
- Position
- Estilização de botões
- Media Queries

#### JavaScript
- Evento de clique
- Redirecionamento entre páginas
- Alertas interativos
- Efeitos nos cards

### Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
